clauses:
--------
--> Clauses are used to control how data is selected,filtered,grouped,sorted or modified in SQL queries.

Think of clauses like instructions given to the database.

Where clause:
------------

Filter records based on specified conditions where clasue can be used as comparison operators, logical operators..etc
syntax:
-------
select column1,column2..from table where condition;

examples:
---------

Group by:
---------

the group by clause is used to group rows having the same values in one or more columns. it is commonly used with aggregate functions such as
sum(),min(),max(),avg(),count().

syntax:
--------
select column_name, aggregate-function(column_name)
from table_name
group by column_name;

examples:
---------

Having clause:
--------------
The having clause is used to filter grouped records after group by clause. It is similar to where but it works on grouped instead of individual rows.

syntax:
------
select column_name,
aggregate_function(column_name)
from table_name group by column_name having condition;

examples:
---------
mysql> select department,count(*) as total_students_count
    -> from students
    -> group by department having total_students_count >2;
+------------+----------------------+
| department | total_students_count |
+------------+----------------------+
| CSE        |                    3 |
| ECE        |                    3 |
+------------+----------------------+
2 rows in set (0.00 sec)

Order By:
----------
Order by clause is used to sort the result set in ascending (ASC) or descending (DESC) order

ASC --> Ascending order
DESC --> Descending order

syntax:
--------
select column_name
from table_name
order by column_name asc;

examples:
---------
